`MathlibAnnex.Projects.GeometricStructureSpaces` facade to public v0.4.0.

resolve to 309 GSS modules and 57 existing Annex providers; the root covers all
328 GSS libraries. The existing five Projects are retained. No unrelated private
research lane is included.
